# 授权、署名、引用与第三方资料 V0.1

## 许可选择

仓库**原创的文字知识内容与原创图文**采用 Creative Commons Attribution 4.0 International（CC BY 4.0）。它允许任何目的的复制、分享与改编，包括商业使用，但适用时必须给予适当署名、标注许可信息并指出修改。法律条款见 https://creativecommons.org/licenses/by/4.0/legalcode 。

仓库 scripts/ 与 .github/workflows/ 内的程序使用 MIT（见 LICENSE-CODE）。这不是“禁止商用”或“衍生品强制同许可”的条款。若未来希望衍生作品也以相同协议公开，应评估 CC BY-SA，而不是未经确认替换现有许可。

## 推荐的醒目来源格式（项目最佳实践）

> 资料来源：装修工程知识图谱（hanpeiyu），《[具体知识卡名称]》，[该卡片永久链接或 GitHub URL]，CC BY 4.0，引用日期 YYYY-MM-DD；如有改写请注明“已改写”。

形式可随媒体变化。CC BY 的法律要求是“适当方式署名”，**不保证所有情况下都必须在同一屏幕显著显示**；此推荐格式属于项目倡议，不额外限制许可本身允许的用途。引用具体卡片优于笼统写仓库名；若有版本/提交 SHA，建议保留。

## 对第三方资料的要求

- 原始检测报告、厂家技术文件、标准全文、图片等，只有在获得相应权利后才能复制/重发；引用链接和短摘要不能变成对原文的转授权。
- 知识卡要分别说明 **本项目作者** 与 **事实/证据原始来源**；本项目作者不能替代检测作者。
- 并非所有事实、数字和想法都受著作权保护；合理使用、公有领域等适用例外不因本说明消失。
- 多人贡献时保留 Git 归属与文件中的署名信息；贡献者必须确认拥有相关文本的许可权或能够合法授权。
- 贡献者未来如要求特别署名，可在各卡片元数据声明；不能删改已有适用的署名义务。
