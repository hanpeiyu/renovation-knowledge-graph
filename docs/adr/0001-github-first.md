# ADR-0001 GitHub 优先的知识源与分层规范

状态：Accepted for V0.1 · 日期：2026-11-12

## 背景

内容会长期扩展、由 AI 协助起草、被多种产品场景复用，需要可编辑、可审阅、可追踪、可结构化索引的格式。

## 决策

GitHub 管理权威 Markdown/YAML/JSON 源文件；架构原则使用 Markdown，类型/关系放 YAML 词表，核心结构由 JSON Schema 约束，Python 脚本和 CI 做语法/引用检查，重要决策保留 ADR。网站、Obsidian 双向引用、关系数据库或推理引擎均从源文件派生。

资料来源引用与原创内容许可分开管理。公开知识优先使用 CC BY 4.0 并保留作者/来源；代码按 MIT。

## 取舍

优势：人/AI 可读、Git 变更历史清楚、无需第一天维护数据库。代价：复杂的关系查询、证据图谱、冲突检查和推理需要后续索引/规则系统，基础 Schema 也不能替代专业审稿。

## 触发复审的条件

节点达到较大规模、反向查询性能不足、协作发生冲突、数据审核或溯源要求无法由文件式架构满足时，可以引入 SQLite/图数据库作为派生查询层；不得未经迁移计划建立第二个权威来源。
