# 样板 A：从一扇门到可验收交付

**案例性质：概念建模演示，不是某品牌报价或工程施工说明。**

## 节点

- OBJ-DOOR-0001：室内门，实物对象。
- OBJ-LOCK-0001：门锁，独立实物对象，作为门的组成部件。
- OBJ-HINGE-0001：合页，独立实物对象，作为门的组成部件。
- ACT-INSTALL-DOOR-0001：室内门安装，工作活动。
- DLV-INSTALLED-DOOR-0001：安装并满足约定验收要求的室内门，交付成果。

## 区分

门锁“可单卖/作为部件”由商业与组成关系表达，不把 product/component 作为互斥类型。

隐形门可能增加门墙界面、节点设计、五金适配与现场复核工作；“可能”不是无条件的增加某个固定设计费。设计工时和是否单独收费分属资源成本与合同边界。

## 推导问题

客户问：“普通门和隐形门为什么价格差距大？”答复应分别检索实物差异、构造要求、深化与协调工作、安装难度、供应商范围、报价条件和验收责任，而不是给出固定溢价百分比。
